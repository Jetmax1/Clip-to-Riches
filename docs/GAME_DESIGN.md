# CLIP TO RICHES — Game Design Summary

## Pillars
1. Discover: find promising moments in fictional livestreams.
2. Create: turn moments into clips through meaningful editing choices.
3. Grow: publish, attract views/followers, and build reputation.
4. Scale: upgrade equipment, hire employees, and automate.
5. Manage: balance cash flow, partnerships, risks, and opportunities.

## Core loop
Watch streams → discover moments → edit clips → publish → receive performance → earn/reinvest → expand.

## Initial streamers
- PixelRage — gaming
- The Daily Mic — podcast
- NovaLive — IRL
- ChaosKing — gaming
- ChillCast — podcast

## Moment categories
Funny, rage, emotional, unexpected, controversial, gameplay, memorable quote.

## Player skills
Editing, Trend Sense, Marketing, Management, Networking.

## Employee roles
Junior Editor, Senior Editor, Trend Researcher, Social Media Manager, Operations Manager.

## Progression locations
Bedroom Office → Creator Studio → Clipping Agency → Large Media Office → International Media Empire.

## Economy principles
- Views are not revenue.
- Monetization eligibility matters.
- Salaries and operating costs matter.
- Virality is probabilistic, not guaranteed.
- Players should have meaningful choices and multiple viable strategies.

## Initial state
$250 cash, 0 followers, 0 employees, basic laptop, bedroom office, 0 reputation.
