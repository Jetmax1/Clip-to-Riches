# Phase 1 — Acceptance Checklist

A Phase 1 build is acceptable only when all of these work:

- [ ] App starts using documented commands.
- [ ] New game initializes with $250, 0 followers, 0 employees.
- [ ] Bedroom office scene renders without errors.
- [ ] Player character and room assets load (placeholders clearly supported).
- [ ] Computer/desk interaction opens Stream Browser.
- [ ] Player can select a fictional streamer.
- [ ] Selected streamer exposes multiple moments.
- [ ] Player can select a moment.
- [ ] Clip editor accepts and validates editing choices.
- [ ] Publishing creates a persistent published-clip record.
- [ ] Performance simulation updates views and engagement.
- [ ] Revenue is calculated only when monetization rules allow it.
- [ ] Followers and cash update consistently.
- [ ] Analytics reflect published clips.
- [ ] Autosave works.
- [ ] Reload restores progress.
- [ ] New Game can start a clean save after confirmation.
- [ ] No visible dead buttons.
- [ ] Type checks and tests pass.
- [ ] First-day gameplay loop is manually verified.
