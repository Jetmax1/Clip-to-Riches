# Agent 2 — Pixel Art Director

Create a consistent visual asset specification and asset pack for CLIP TO RICHES.

Art direction:
- 16-bit pixel art
- Cozy dark bedroom-office mood
- Purple/cyan/blue accents
- Consistent pixel scale, outlines, perspective, and lighting
- Readable silhouettes at browser-game scale

Deliver:
- Palette and pixel-scale guide
- Player sprite sheet specification
- Bedroom background and tileset
- Furniture and computer sprites
- UI icon set
- Asset manifest with filenames, dimensions, frame layout, and intended use

Prefer separate transparent sprites over flattened screenshots. Do not include text in generated art.
Do not mix incompatible perspectives or pixel densities. Record licenses and sources for third-party assets.
