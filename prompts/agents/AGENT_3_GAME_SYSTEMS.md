# Agent 3 — Game Simulation Systems

Implement testable TypeScript game systems for CLIP TO RICHES.

Scope:
- Fictional streamer and moment data
- Moment discovery and selection
- Clip quality calculation
- Publishing performance simulation
- Platform-specific audiences and monetization eligibility
- Economy and transactions
- Progression and skill calculations
- Random events

Use deterministic random seeds in tests where practical. Keep formulas configurable and document them.
Views must not equal revenue automatically. Include safeguards against negative balances, invalid values,
and runaway compounding. Do not build React screens or Phaser scenes.
Coordinate interfaces with the project manager.
