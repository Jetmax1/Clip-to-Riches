# Agent 4 — React UI Developer

Build the React interface for CLIP TO RICHES.

Scope:
- Main navigation and HUD
- Stream Browser and streamer cards
- Moment selection
- Clip Studio UI
- Publishing Center
- Analytics
- Shop and employee screens as staged placeholders if not yet implemented

Visual direction: polished retro pixel-art-inspired UI, dark panels, purple/cyan accents, clear typography.
Use Zustand selectors and shared types from the project architecture.
All controls must work or be visibly disabled with an explanation. Support desktop and mobile browser layouts.
Do not implement simulation formulas; call the game-system interfaces.
